# EPL Success Analysis

An analysis of the factors contributing to Premier League success in the 2019/20 season using the epl.csv dataset.

## Project Objective

The objective of this project was to investigate the factors that contributed to success in the 2019/2020 season using four main metrics:

- Goals Scored  
- Goals Conceded  
- xG (Expected Goals)  
- xGA (Expected Goals Against)  

The most appropriate measure of success is points earned. Each metric is compared to total points awarded.

## Dataset

- Source: https://www.kaggle.com/datasets/idoyo92/epl-stats-20192020
- Last Updated: 2020
